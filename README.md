# Portfolio Website Export

这是已经整理好的完整静态网站项目包。

## 运行方式

1. 解压 ZIP。
2. 双击 `start-server.bat`。
3. 浏览器打开：

```text
http://127.0.0.1:4180/index.html
```

常用页面：

```text
首页：http://127.0.0.1:4180/index.html
分类页：http://127.0.0.1:4180/category.html?cat=portrait
精品项目页：http://127.0.0.1:4180/featured.html?project=ad
```

## 项目结构

```text
index.html              首页
category.html           分类二级页面
featured.html           精品项目二级页面
styles.css              全站样式
script.js               首页脚本
category-data.js        分类项目数据
category-page.js        分类页面脚本
featured-projects.js    精品项目数据和脚本
assets/                 图片、视频等素材
data/                   数据文件
admin/                  管理相关文件
```

临时预览截图、浏览器缓存和服务日志没有打进 ZIP。
